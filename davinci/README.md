# Titulky pre DaVinci Resolve – šablóna „Subtitle Clean“

Biely tučný text s čiernym obrysom a jemným tieňom, dolu uprostred obrazu.

## Inštalácia
Skopíruj `Subtitle Clean.setting` do priečinka:

- **Windows:** `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Titles\`
- **macOS:** `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Templates/Edit/Titles/`
- **Linux:** `~/.local/share/DaVinciResolve/Fusion/Templates/Edit/Titles/`

Reštartuj Resolve. Nájdeš ju v **Effects → Titles → Subtitle Clean**, pretiahni na timeline.

## Úpravy
V Inspectore: text, font, veľkosť, pozícia, farba textu, hrúbka obrysu.

## Poznámka
Šablóna nebola testovaná priamo v Resolve. Ak sa nenačíta, daj vedieť.
Pre celé SRT titulky: Resolve → File → Import → Subtitle, potom vo vlastnostiach
titulkovej stopy nastav font, veľkosť a obrys.
