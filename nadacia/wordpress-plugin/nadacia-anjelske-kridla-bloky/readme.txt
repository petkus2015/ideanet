Hotové sekcie jednostránky nadácie pre Avada Builder.

== Description ==

Plugin pridá do Avada Library dvanásť pripravených sekcií webu nadácie: hero
s posuvačom fotiek, čísla, o nás, ako pomáhame, žiadosť o pomoc s tlačivami,
projekty, články, galéria, 2 % z dane, podpora s číslom účtu, príbehy a kontakt.

Sekcie sa vkladajú cez Avada Builder → Library → Containers a ďalej sa upravujú
klikaním ako každý iný obsah. Plugin zároveň pridá štýly, ktoré doladia
nadpisíky sekcií, číslované kroky, údaje pre vyhlásenie a rámček s číslom účtu,
a nesie ilustračné obrázky, aby sekcie vyzerali hotovo hneď po vložení.

== Installation ==

1. Nástenka → Pluginy → Pridať nový → Nahrať plugin → vyberte ZIP → Inštalovať.
2. Plugin aktivujte.
3. V ľavom menu otvorte "Bloky nadácie" a kliknite na "Importovať bloky do
   Avada Library".
4. Sekcie potom nájdete v builderi pod ikonou Library.

Plugin vyžaduje tému Avada a aktívny Avada Builder (Fusion Builder).
